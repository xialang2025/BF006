## 串口验收脚本

在仓库根目录运行。软件模拟使用电脑端 C 编译器（默认 `gcc`，可用环境变量 `CC` 指定），通过现有固件测试代码执行 UART4 收发、参数处理和模拟存储。实板串口需要 Python 和 `pyserial`（`python -m pip install pyserial`）。

```powershell
$验收脚本 = 'BF006_STC/pro/tests/run_bf4g_serial_acceptance.py'
python -X utf8 $验收脚本 simulate --pumps 1
python -X utf8 $验收脚本 simulate --pumps 2
python -X utf8 $验收脚本 simulate --pumps 2 --drop-address-ack
```

前两个命令验证读取、写入、改址与控制，并对比恢复前后的全部参数和运行模式。第三个命令模拟改址已经执行且应答丢失，预期验收退出码为 `1`，同时 `result.json` 显示 `simulation_restored_snapshot: true`、`pending: {}`。

接好独立测试板后先列出串口，再用设备当前地址做只读验收。以下 `COM5` 和地址 `1` 为示例。

```powershell
python -X utf8 $验收脚本 list
python -X utf8 $验收脚本 run --port COM5 --address 1 --board BF006-01
```

完成板型和无动力负载核对后，可以显式指定要试写的参数与控制演练。参数值使用线上原始整数，示例的 `P-03=120` 对应 `12.0 A`。重复使用 `--set` 可按给出的顺序试写多项。调整量程与阈值时，先扩大后抬高阈值，先降低阈值后缩小量程。确认测试地址空闲后可用 `--set P-11=2` 试验改址。使用 `--clear-fault` 会额外执行一次当前故障清除，故障历史和累计数据保留。

```powershell
python -X utf8 $验收脚本 run --port COM5 --address 1 --set P-03=120 --exercise-control
```

程序在控制台打印验收目录。可通过 `--output` 指定新目录。每个目录的 `traffic.jsonl` 记录时间、方向、地址、关联号、完整十六进制帧及超时；`backup.json` 保存写前读数和待恢复项；`result.json` 记录结果、恢复核对与待恢复项。写前登记可能改变的项目，结束时由实际读回判断是否需要恢复，恢复后再次核对。当前值已是原值时直接核销。发现计划外值时将该项保留待核对。

遇到断线或中断导致 `pending` 未清空时，重新接上**同一块测试板**后使用原备份续恢复。设备信息只有机型和固件版本，现场须核对板号，恢复命令会在记录中的原地址和试写地址间做只读探测。

```powershell
python -X utf8 $验收脚本 restore --port COM5 --backup 'C:/BF4G/上次验收/backup.json'
```

串口验收核对内存读回。硬件继电器、LCD、发送与擦写时序、栈水位和断电后的存储读回仍在下表单独登记。
