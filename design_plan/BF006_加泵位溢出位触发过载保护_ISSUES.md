## ISSUE-01：实现一控一加泵位触发 A 泵过载完整链路

### 类型

AFK

### 建议标签

`ready-for-agent`

### 父需求

`BF006_加泵位溢出位触发过载保护_PRD.md`

### 要构建的内容

在一控一机型中，将加泵位完整改造为 A 泵触点过载保护输入。输入通过现有高电平滤波后，无论 A 泵是否正在运行、处于哪种运行模式或配置了什么参数，都必须形成现有 A 泵过载故障、停止并禁止 A 泵运行。

该切片同时建立可复用的触点过载来源标识和锁存周期，使程序能够区分触点触发过载与普通电流过载。触点断开后故障继续保持；触点断开并执行显式清除后才能恢复；自动恢复不得解除触点过载。显示、Modbus、4G 和历史故障记录沿用现有 A 泵过载语义，不再产生原溢出状态。

### 验收标准

- [ ] 一控一机型的加泵位持续高电平通过现有滤波后，置位现有 A 泵过载故障并停止 A 泵。
- [ ] 短时高电平毛刺未通过滤波时，不触发 A 泵过载。
- [ ] A 泵正在运行和未运行两种情况下均能触发；未运行时仍保持故障并禁止后续启动。
- [ ] 手动、自动、定时模式下的触发结果一致。
- [ ] 故障屏蔽、传感器模式、过载阈值、启动延时和自动恢复时间均不能阻止触点触发。
- [ ] 触点断开后，A 泵过载故障、停机状态和对外上报继续保持。
- [ ] 触点断开后，面板按键、遥控器、Modbus 和 4G 显式清故障动作均可解除 A 泵触点过载锁存。
- [ ] 触点仍接通时执行任何显式清故障动作，最终仍保持 A 泵过载，A 泵不能恢复运行。
- [ ] 自动恢复时间非零且等待超过恢复时间后，A 泵触点过载仍不自动清除。
- [ ] 同一锁存周期只写一条 A 泵过载历史记录，持续扫描和无效清除不重复写记录。
- [ ] 输入断开并成功清除后再次接通，形成新的锁存周期并新增一条历史记录。
- [ ] 断电后输入保持断开再上电，不恢复旧故障；上电时输入已接通，则在滤波后重新触发。
- [ ] 现场显示、Modbus 和 4G 只表现为现有 A 泵过载，不显示或上报原溢出状态。
- [ ] 普通电流触发的 A 泵过载仍按既有阈值、记录和自动恢复规则运行。

### 前置依赖

无，可立即开始。

## ISSUE-04：实现一控二双输入并发和两泵独立故障处理

### 类型

AFK

### 建议标签

`ready-for-agent`

### 父需求

`BF006_加泵位溢出位触发过载保护_PRD.md`

### 要构建的内容

完成一控二机型中加泵位和溢出位同时或先后触发时的组合行为。A、B 两路触点保护必须分别判断、分别锁存、分别停泵并分别记录，任何一路状态变化都不能覆盖另一条故障链路。

当两个输入同时有效时，两台泵都形成对应的现有过载故障并停机。当只有一路触点断开并满足清除条件时，仅允许解除该路锁存；另一条仍有效或未清除的故障继续保持。显示和通信遵循现有双泵故障表达，不额外产生加泵或溢出状态。

### 验收标准

- [ ] 加泵位和溢出位在同一滤波周期内变为有效时，A 泵和 B 泵分别置位对应过载故障并全部停机。
- [ ] 两个输入先后变为有效时，后触发的故障不会覆盖先触发故障。
- [ ] 两路故障各写一条对应泵历史记录，持续有效期间均不重复写记录。
- [ ] 仅加泵位有效时只停止 A 泵，B 泵可按原逻辑运行。
- [ ] 仅溢出位有效时只停止 B 泵，A 泵可按原逻辑运行。
- [ ] 两路均已锁存后，只断开并成功清除 A 路时，B 泵过载仍保持。
- [ ] 两路均已锁存后，只断开并成功清除 B 路时，A 泵过载仍保持。
- [ ] 一路触点仍接通期间执行全局或对应泵清除动作，该路最终仍保持过载并禁止启动。
- [ ] 一路清除后再次触发，只为该路新增新的历史记录，不影响另一条锁存周期。
- [ ] 现场显示能区分 A 泵和 B 泵过载，Modbus 和 4G 沿用现有故障表达且不增加溢出或加泵状态。
- [ ] 在手动、自动、定时模式下重复组合场景，结果保持一致。

- ISSUE-02：一控二加泵位到 A 泵过载链路。
- ISSUE-03：一控二溢出位到 B 泵过载链路。
