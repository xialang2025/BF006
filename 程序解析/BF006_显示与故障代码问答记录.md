日期：2026年5月1日

本文档整理当前会话中关于 BF006 程序显示接口、参数显示、故障代码上报的分析记录。内容来自对 `BF006_STC\src` 和 `BF006_STC\pro` 中现有程序的只读分析，未修改程序代码。

## 1. 新增参数是否需要修改液晶显示程序

### 用户问题

这个程序中如果新增参数，修改液晶显示的程序吗？发了哪些变量给显示用。显示由另一个芯片驱动。

### 分析结论

新增参数不一定要改液晶显示程序。

如果只是新增一个内部参数，或者只给通讯读取、写入使用，主要修改参数表和通讯映射即可。只有这个新参数要在本机 `P-xx` 参数菜单里显示、编辑，或者外部显示芯片需要显示、设置它，才需要同步修改显示侧逻辑或通讯协议。

当前本机参数菜单由 `BF006_STC\src\user.c` 管理：

- `PAR_NUMB`：当前参数数量。
- `par[]`：参数表，绑定 `config.xxx`、最大值、最小值和显示类型。
- `DIS_Control()`：运行显示和参数页显示控制。
- `Dis_parEidt()`：参数编辑值显示控制。

当前程序中参数数量为 21 个，显示为 `P-00` 到 `P-20`。如果只是新增 `P-21`，并且参数类型仍属于已有类型，一般主要修改 `PAR_NUMB` 和 `par[]`。如果新增参数单位或显示方式不同，则需要检查 `Dis_parEidt()` 是否要增加新的显示类型。

## 2. 当前程序可以报出的故障代码

### 用户问题

现在程序中可以报出哪些故障代码？

### 分析结论

当前程序里至少有三种故障代码口径：

- 内部故障编号：`system.h` 中 `ERR_xxx` 宏，0 起编号。
- 4G / JSON 上报代码：`updata4G.c` 中 `Light_Status`，大多转换为负数。
- 新版 Modbus 当前故障代码：`Modbus_New.c` 中 `modbus_new_current_fault()`，返回内部编号加 1。

### 内部故障编号

定义在 `BF006_STC\src\system.h`。

| 内部编号 | 宏 | 含义 |
|---:|---|---|
| 0 | `ERR_UVP` | 欠压 |
| 1 | `ERR_OVP` | 过压 |
| 2 | `ERR_OVERLOAD1` | A泵过载 |
| 3 | `ERR_STANDBY1` | A泵空载或缺水保护 |
| 4 | `ERR_LOSE_A1` | A泵 A 相缺相 |
| 5 | `ERR_LOSE_B1` | A泵 B 相缺相 |
| 6 | `ERR_LOSE_C1` | A泵 C 相缺相 |
| 7 | `ERR_OVERLOAD2` | B泵过载 |
| 8 | `ERR_STANDBY2` | B泵空载或缺水保护 |
| 9 | `ERR_LOSE_A2` | B泵 A 相缺相 |
| 10 | `ERR_LOSE_B2` | B泵 B 相缺相 |
| 11 | `ERR_LOSE_C2` | B泵 C 相缺相 |
| 12 | `ERR_SENSOR` | 传感器故障，当前定义了但未看到作为 `Fault_Error` 设置 |
| 13 | `ERR_NOLOAD_A` | A泵无负载，显示函数有处理，但设置处被注释 |
| 14 | `ERR_NOLOAD_B` | B泵无负载，显示函数有处理，但设置处被注释 |
| 15 | `ERR_LOCK_A` | A泵锁机 |
| 16 | `ERR_LOCK_B` | B泵锁机 |
| 17 | `ERR_NUMB` | 无故障或故障数量边界 |

### 4G / JSON 上报字段 `Light_Status`

转换逻辑在 `BF006_STC\src\updata4G.c`。

| `Light_Status` | 对应故障 |
|---:|---|
| 0 | 无故障 |
| -2 | 欠压 |
| -3 | 过压 |
| -4 | A泵 A 相缺相 |
| -5 | A泵 B 相缺相 |
| -6 | A泵 C 相缺相 |
| -7 | A泵空载或缺水保护 |
| -8 | A泵过载 |
| -9 | B泵 A 相缺相 |
| -10 | B泵 B 相缺相 |
| -11 | B泵 C 相缺相 |
| -12 | B泵空载或缺水保护 |
| -13 | B泵过载 |
| -14 | 传感器故障，来自 `sys.sensor_err` |
| -15 | 溢出或满水相关报警，来自 `sys.flowover` |

注意：

- `ERR_LOCK_A` 和 `ERR_LOCK_B` 没有单独映射到 `Light_Status`。
- `ERR_NOLOAD_A` 和 `ERR_NOLOAD_B` 没有单独映射到 `Light_Status`。
- 如果只进入上述未映射的内部故障，4G 上报逻辑默认可能报 `0`，除非同时存在 `sys.sensor_err` 或 `sys.flowover`。

### 新版 Modbus 当前故障代码

转换逻辑在 `BF006_STC\src\Modbus_New.c` 的 `modbus_new_current_fault()`。

返回规则：

- `0`：无故障
- 有故障时：返回“内部编号 + 1”

| Modbus 当前故障代码 | 对应内部故障 | 含义 |
|---:|---|---|
| 0 | 无 | 无故障 |
| 1 | `ERR_UVP` | 欠压 |
| 2 | `ERR_OVP` | 过压 |
| 3 | `ERR_OVERLOAD1` | A泵过载 |
| 4 | `ERR_STANDBY1` | A泵空载或缺水保护 |
| 5 | `ERR_LOSE_A1` | A泵 A 相缺相 |
| 6 | `ERR_LOSE_B1` | A泵 B 相缺相 |
| 7 | `ERR_LOSE_C1` | A泵 C 相缺相 |
| 8 | `ERR_OVERLOAD2` | B泵过载 |
| 9 | `ERR_STANDBY2` | B泵空载或缺水保护 |
| 10 | `ERR_LOSE_A2` | B泵 A 相缺相 |
| 11 | `ERR_LOSE_B2` | B泵 B 相缺相 |
| 12 | `ERR_LOSE_C2` | B泵 C 相缺相 |
| 13 | `ERR_SENSOR` | 传感器故障 |
| 14 | `ERR_NOLOAD_A` | A泵无负载 |
| 15 | `ERR_NOLOAD_B` | B泵无负载 |
| 16 | `ERR_LOCK_A` | A泵锁机 |
| 17 | `ERR_LOCK_B` | B泵锁机 |

### 当前复核备注

1. 内部故障定义包含 `ERR_SENSOR`，但实际传感器异常主要通过 `sys.sensor_err` 参与 4G 上报，未看到作为 `Fault_Error` 位设置。
2. `ERR_NOLOAD_A`、`ERR_NOLOAD_B` 在显示函数中有处理，但系统故障设置处相关代码被注释。
3. 4G `Light_Status` 对锁机故障和无负载故障没有独立负数代码映射。
4. 新版 Modbus 会按 `Fault_Error` 中最低编号的故障位返回当前故障，多个故障同时存在时只返回优先级最高的一个当前故障代码。
